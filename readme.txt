NDS-Chat-Program

Program Build located in BlueChat_v1.0 Folder.

A uni project for the subject network and database systems from Torrens University.
Modified working TCP chat application with missing and limited features.
Path to build - NDS-Chat-Program\Windows Forms core chat\bin\Debug\net10.0-windows7.0

Commands List:

CLIENT:
!user - change username
!kick - kick specifed user if your a mod
!commands - show list of commands
!exit - disconnect from chatroom
!who - show list of connected clients
!about - show author details
!whisper - send message to specified user
!color - change your text color EXAMPLE: (!color red)
!scores - show game scores
!join - join tic tac toe game.

SERVER:
!kick - kick specified client
!mods - show list of mods
!mod - elevated specified user to moderator
